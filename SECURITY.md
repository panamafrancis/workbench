# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security problem. Report it privately through GitHub's [private vulnerability reporting](https://github.com/panamafrancis/workbench/security/advisories/new) instead. If the problem is in code shared with [supatree](https://github.com/panamafrancis/supatree), report it on the repo it mostly belongs to; we will coordinate a fix across both.

Include what you found, how to reproduce it, and the version (`workbench version`) or commit you tested. We aim to acknowledge a report within a week and will keep you posted until it is fixed and released.

## Supported versions

Only the latest release gets security fixes.
